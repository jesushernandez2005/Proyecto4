## 📖 Documentación

Esta página está realizada utilizando **MkDocs + Material for MkDocs**.

Para visualizar la página localmente:

```bash
python -m mkdocs serve
```

Después se puede abrir:

```text
http://127.0.0.1:8000/
```

Para generar la página:

```bash
python -m mkdocs build
```
